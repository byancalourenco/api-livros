## 📖 Sobre o projeto

Este projeto foi desenvolvido como uma **atividade do 3º bimestre da disciplina de Sistemas Web II**, com o professor **Anderson Vanin**.

A proposta é construir uma **aplicação web para gerenciamento de livros**, começando pela criação do banco de dados e da API e finalizando com uma interface completa para utilização no navegador.

O sistema será desenvolvido utilizando **Python, FastAPI, MySQL, HTML, CSS e JavaScript**, permitindo realizar as principais operações de gerenciamento de livros, como cadastrar, consultar, editar e excluir registros.

Durante o desenvolvimento, o projeto também permite colocar em prática conceitos de **API REST, banco de dados, CRUD, validação de dados, tratamento de erros, consumo de APIs e versionamento com Git e GitHub**.

---

## 🎯 Objetivos

O principal objetivo deste projeto é desenvolver uma aplicação web completa para **gerenciamento de livros**, integrando banco de dados, API e interface web.

O sistema tem como objetivos:

* Criar uma API para gerenciamento dos livros;
* Permitir o cadastro, consulta, edição e exclusão de livros;
* Armazenar as informações em um banco de dados MySQL;
* Desenvolver uma interface para interação com o usuário;
* Integrar o front-end com a API utilizando `fetch`;
* Implementar validação dos dados e tratamento de erros;
* Organizar o projeto utilizando boas práticas de desenvolvimento;
* Utilizar Git e GitHub para acompanhar e registrar a evolução do projeto.

## 📋 Etapas do projeto

O projeto foi dividido em **4 etapas**, acompanhando a construção e evolução da aplicação, desde a configuração inicial até a interface final.

### 🔹 Etapa 1 — Estrutura inicial

Configuração do ambiente, instalação das dependências, criação do banco de dados `biblioteca_db` e conexão da aplicação com o MySQL.

Também é criada a estrutura inicial da API utilizando FastAPI.

---

### 🔹 Etapa 2 — Livros e API

Criação do modelo `Livro` e dos schemas responsáveis pela organização e validação dos dados.

Nesta etapa também são implementadas as primeiras operações da API para **cadastrar e consultar livros**, utilizando `POST` e `GET`.

---

### 🔹 Etapa 3 — Gerenciamento completo

A API passa a permitir o gerenciamento completo dos livros, com a implementação das operações de **edição e exclusão**, utilizando `PUT` e `DELETE`.

Também são realizados os tratamentos de erros e testes das funcionalidades.

---

### 🔹 Etapa 4 — Interface web

Desenvolvimento da interface utilizando **HTML, CSS e JavaScript** e integração com a API através do `fetch`.

Nesta etapa, o usuário passa a conseguir **cadastrar, visualizar, editar e excluir livros diretamente pelo navegador**.
